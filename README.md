# Absentee

Прототип игры про космическую империю, которой нельзя управлять напрямую.

Игрок — государство. Всё делают компании: добывают, строят, изучают,
расселяются, торгуются и отказывают друг другу. Игрок не приказывает, а меняет
выгодность: налоги, субсидии, срок патента, торговый сбор, пособие.

**Задача игрока — своими указами бороться за то, чтобы колонии выжили внутри
государства, а не отделились.** Свежая колония десять лет живёт в разруху и
на привозной еде; четыре года голода — и она доходит до края, а что из этого
выйдет, решает жребий: люди скинутся в свою артель, или возьмутся за оружие и
станут грабить всё, что летит мимо, или объявят независимость и заберут
филиалы компаний — и тогда в галактике появляется второе государство со своим
гербом, который с этого дня виден над его планетами и кораблями. Компании стараются этого не допустить, потому что теряют
филиалы, но им не хватает то денег, то топлива, то желания продавать. Рычаги
государства должны сделать так, чтобы им хватало.

## Как запустить

Онлайн, ничего не ставя: https://pashtetus1.github.io/Absentee/ — каждая ветка
репозитория выложена по своему адресу.

Локально нужен Node:

```bash
npm install
npm run build
```

Дальше открыть `dist/index.html` в браузере — это один самодостаточный файл,
без сервера. Пока правишь, удобнее так:

```bash
npm run watch
```

Сборка идёт за десятки миллисекунд, поэтому цикл прежний: поправил число,
нажал F5.

Каждая партия помечена сидом: он виден в строке сводки и стоит в адресе
страницы (`...#seed=12345`). Увидел странное — пришли ссылку, и та же партия
развернётся у любого, включая тесты. Сид можно вписать в адрес руками:
страница пересоберёт партию, не дожидаясь перезагрузки. «Заново» берёт новый.

## Устройство

Игра пишется исходниками в `src/` на TypeScript и собирается в один
`dist/index.html`. Готового файла в репозитории нет: `dist/` в `.gitignore`,
для Pages его собирает CI.

```
src/data.ts      таблицы: детали, классы миров, типы планет, способы перелёта
src/state.ts     всё изменяемое состояние партии и правила работы с ним
src/util.ts      чистые мелочи без памяти
src/setup.ts     build() — сборка новой партии
src/tick.ts      step() — один месяц, в каком порядке что происходит
src/*.ts         по файлу на подсистему: галактика, миры, труд, еда, стоянки,
                 помощь, переселение, наука, производство, рынок, заказы,
                 движение, экономика, край и жребий, пиратство
src/render/      отрисовка: холст, модельки, сцена, панели, управление
```

`src/types.ts` описывает формы предметных объектов: мир, компания, планета,
рейс, заказ. Это не украшение — ядро когда-нибудь переедет на C#, и эти
интерфейсы черновик будущих структур (журнал, п. 9).

Отрисовка только ЧИТАЕТ состояние и никогда не пишет в него. Раньше это было
соглашением, теперь правилом языка: присвоить чужую переменную в ES-модулях
нельзя, и нарушение падает при сборке.

Проверка типов отдельно:

```bash
npm run check
```

## Тесты

```bash
npm test
```

Сначала проверяет типы, потом собирает `dist/index.html`, потом гоняет по нему
полсотни проверок. Тесты тоже на TypeScript и запускаются как есть, без
отдельной сборки: типы срезает сам Node (нужен Node 22.6+, проверено на 24).

Проверки: стенд вырезает
ядро из собранного файла, подсовывает заглушки DOM и генератор случайных чисел
с сидом, прогоняет 150-300 симулированных лет. Они ловят поломки, а не скуку.

Полный набор идёт около минуты — это десятки миллионов симулированных тиков.
Пока правишь одно правило, гонять всё незачем, есть отбор по имени:

```bash
node test/run.ts опустевший          # только проверки со словом в имени
node test/run.ts опустевший герб     # любая из двух, регистр не важен
npm test -- опустевший               # то же, но сперва типы и сборка
```

Две проверки вместо семидесяти семи — семь секунд вместо минуты. В итоговой
строке при этом стоит, сколько пропущено: частичный прогон обязан выглядеть
частичным, зелёная строка после отбора не значит, что набор цел. Отбор, не
подошедший ни к одному имени, печатает весь список имён и падает — иначе
опечатка выглядела бы как успех.

Перед коммитом всё равно нужен полный прогон: партия целиком определяется
сидом, и ЛЮБАЯ правка правил сдвигает расход случайности — партия
пересобирается, и проверка на другом конце игры может перевернуться, не будучи
сломанной.

Отдельно есть сличитель партий:

```bash
node test/compare.ts старый.html dist/index.html
```

Он гоняет два файла на одних сидах до 300 года и сравнивает казну, счётчики,
рынок, патенты, компании и миры. Нужен, когда правка обязана НИЧЕГО не менять
в поведении — например при перекладывании кода.

И прогон баланса на многих партиях сразу:

```bash
node test/sweep.ts                    # 100 партий по 300 лет
node test/sweep.ts dist/index.html 8  # восемь — тогда каждая партия строкой
```

Сиды раздаются по процессам, сто партий идут секунд за двенадцать. Считает
миров, людей, голодающих и хлебовозы, летевшие навстречу друг другу. Это
инструмент для правок баланса: сначала прогон, потом мнение.
